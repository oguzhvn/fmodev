# KAP raporları

Buraya şu 4 konsolide "Finansal Rapor" PDF'ini koyun (Faaliyet Raporu veya Sorumluluk Beyanı değil):

1. `MGROS_2025Q4.pdf`: Migros, 31.12.2025 finansal tabloları
2. `MGROS_2026Q2.pdf`: Migros, 30.06.2026 finansal tabloları
3. `BIMAS_2025Q4.pdf`: BİM, 31.12.2025 finansal tabloları
4. `BIMAS_2026Q2.pdf`: BİM, 30.06.2026 finansal tabloları

Rakamlar `veri.json` dosyasına girilir. Ardından `python3 scripts/build_excel.py` komutu Excel'i yeniden oluşturur.
